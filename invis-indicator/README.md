# Invis Indicator (Fabric, Minecraft 26.1.2)

Клиентский мод: рисует настраиваемое кольцо (+ опционально ник) над игроками,
у которых активен эффект невидимости. Не даёт «wallhack»/ESP:

- кольцо рисуется только для сущностей, которые и так есть в обычной
  прорисовке (не расширяет дальность обнаружения);
- используется тот же синхронизируемый флаг `isInvisible()`, из-за которого
  ванильный клиент и так перестаёт рисовать модель — никакой скрытой
  информации не добывается;
- рендер идёт с включённым тестом глубины, поэтому кольцо перекрывается
  стенами/блоками так же, как обычная модель.

**Перед использованием на конкретном сервере проверь его правила** — то, что
разрешено на одном сервере (как на скрине HolyWorld, который ты присылал),
может быть запрещено на другом.

## Сборка

```bash
./gradlew build
```

Собранный джар будет в `build/libs/invis-indicator-1.0.0.jar`.
Кидаешь его в папку `mods` вместе с Fabric API нужной версии.

## ВАЖНО: версия API может отличаться

Minecraft 26.1.2 вышел позже моего среза знаний, поэтому часть точных имён
классов/методов Fabric API и Mojang mappings я собрал через веб-поиск
(например, переименование `WorldRenderEvents` → `LevelRenderEvents`, переход
на официальные маппинги Mojang вместо Yarn), но не могу гарантировать на
100%, что *все* сигнатуры (особенно у `LevelRenderEvents.AfterEntities`,
`VertexConsumer.addVertex/setColor/setNormal`, `EntityRenderDispatcher`)
совпадают тютелька в тютельку с 26.1.2 — рендер-пайплайн последний год менялся
активно (переход к Blaze3D/GPU-буферам, подготовка к Vulkan в 26.2).

Если при сборке будут ошибки компиляции — это почти всегда несовпадение
метода на 1 сигнатуру. Быстро чинится через IDE (IntelliJ/VS Code с
Fabric-plugin подтянет sources jar с реальными именами) — просто открой
`RingRenderer.java` и `InvisIndicatorClient.java`, наведи на
подсвеченный красным метод и возьми правильное имя/аргументы из autocomplete.
Если что-то не билдится — присылай мне текст ошибки, поправлю под точную
сигнатуру.

## Команды

- `/invisindicator color RRGGBB` — цвет кольца, например `/invisindicator color FF3B30`
- `/invisindicator radius 0.1..3` — радиус кольца
- `/invisindicator alpha 0.05..1` — прозрачность
- `/invisindicator nickname true|false` — показывать ли ник

Настройки сохраняются в `config/invisindicator.json`.
